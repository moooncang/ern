# 변경의 신임 영주가 되었다 — 소개 사이트

크랙 캐릭터 챗 작품 「변경의 신임 영주가 되었다」의 소개 사이트다.

- 사이트: https://moooncang.github.io/ern/
- 기획서: [PLAN.md](PLAN.md) — 컨셉, 쪽별 설계, 글 원칙, 아직 비어 있는 것

## 폴더

```
index.html              입장(서임장)
home.html               첫 화면
world.html              세계
domain.html             영지
characters.html         인물 고르는 화면
char/a.html ~ l.html    인물 상세 12쪽
start.html              시작
music.html              음악 3곡과 재생 조작
assets/css/style.css    모양
assets/js/main.js       동작
assets/js/sfx.js        녹음된 효과음 재생·음소거
images/                 인물 원화 변환본·제작한 UI 삽화
audio/music/            사용자가 제공한 원본 MP3
audio/sfx/              짧게 편집한 효과음 14개·출처·라이선스
_build/data.py          글과 경로 전부
_build/music_data.py    곡 제목·음원·표지·길이
_build/build.py         쪽을 찍어 내는 스크립트
```

## 고치는 법

HTML은 직접 고치지 않는다. 메뉴와 바닥글이 쪽마다 겹치므로 스크립트가 19쪽을 한 번에 다시 찍는다.

1. 글, 수치, 그림 경로는 `_build/data.py`에서 고친다
2. 사이트 폴더에서 다시 찍는다

```
python _build/build.py
```

3. `main`에 푸시하면 GitHub Pages에 반영된다

`build.py`는 파이썬 기본 기능만 쓴다. 다 찍은 뒤 쪽과 CSS가 가리키는 파일이 실제로 있는지 검사하고, 없으면 멈춘다.

기본 모양은 `assets/css/style.css`, 동작은 `assets/js/main.js`에서 고친다. CSS·스크립트 경로에는 내용 해시가 붙으므로 수정 후 HTML도 다시 생성한다.

## 미리 보기

```
python3 _build/serve.py --port 8765
```

브라우저에서 `http://localhost:8765/`를 연다.

이 서버는 MP3의 바이트 범위 요청을 지원하므로 재생 위치 이동과 페이지 이동 후 위치 복원을 실제 음원으로 확인할 수 있다.

## 원래 기획을 유지한 디자인 보강

문구와 쪽 구성, 인물 구도는 `PLAN.md`를 기준으로 유지한다. `assets/css/materials.css`는 기본 재질, `craft.css`는 내부 화면의 마감·정렬·반응형 배치, `entry.css`는 봉투와 서임장의 표현을 담당한다.

- `images/ui/wax-seal.webp`: 기존 참나무잎 문양으로 제작한 투명 밀랍 에셋. 봉투 봉인과 명부·문서의 인장에 사용한다.
- `images/ui/envelope.webp`, `letter-sheet.webp`: 접힌 덮개·금박·종이 두께를 표현한 봉투와 서임장 이미지. 봉인을 떼면 덮개가 열리고 서임장이 나타난다.
- `images/ui/leather-plate.webp`, `banner-cloth.webp`: 인물·영지 명패와 세력 깃발에 사용하는 가죽·직물 이미지.
- `images/ui/parchment.webp`: 기존 양피지 색 위에 약하게 적용하는 종이결.
- `_build/engraving.py`: 기존 지도·영지 SVG에 더하는 세부 판화선. 설정·지역·성장 단계는 바꾸지 않는다.
- `assets/css/fonts.css`, `assets/fonts/`: 원래 세 글꼴과 두께를 그대로 자체 호스팅한다. OFL 라이선스와 출처는 해당 폴더에 있다.

입장 화면은 320px 모바일부터 가로 화면까지 중앙에 정렬하며, 열린 서임장이 화면보다 길면 세로로 스크롤된다. 키보드로 봉인을 열 수 있고, 이름 입력 중 Enter를 누르면 확인 버튼으로 이동한다. 동작 줄이기 설정도 따른다.

원문·기획 보존 검사는 `python3 tests/preserve_plan.py`로 실행한다. 미리 보기 서버와 Playwright·Chromium을 준비하면 `python3 tests/original_smoke.py --base-url http://127.0.0.1:8766/`으로 18쪽의 기능과 입장 화면의 정렬·키보드 동작을 확인할 수 있다.

## 전체 에셋 적용

초기 기획의 문구·화면 순서·여섯 인물 표지는 유지하며, 코드로 그렸던 시각 요소 위에 제작한 삽화를 적용한다. `images/atelier/`의 WebP는 이 사이트를 위해 이미지 생성으로 제작한 에셋이다. 인물 원화는 교체하지 않는다.

- 영지 성장: 같은 시점과 화풍으로 제작한 개척지부터 대도시까지 여섯 전경. 슬라이더와 기존 수치·시설 설명을 유지한다.
- 약도: 기존 지역 좌표·라벨·경로 위에 손으로 그린 지도와 여섯 지역 풍경을 적용한다. `_build/map_art.py`와 `map-art.css`가 담당한다.
- 세력·사계: 네 가지 자수 깃발과 네 장의 계절 세밀화. `emblems.css`에서 기존 선택·태도 동작과 결합한다.
- 문서: 하사·계승·자유모드 소품 삽화, 금화·은화·동화 장부 삽화, 참나무·밀 테두리 종이를 카드·장부·노트·인물 기록에 재사용한다. 기본 적용은 `atelier.css`, 연필 도판과 문서 배치는 `manuscript.css`가 담당한다.
- 입장: 밀랍 해제 → 덮개 열기 → 편지 꺼내기 → 깃펜으로 칙서 쓰기의 순서로 동작한다. 봉투는 편지 아래에 놓인 채 남는다. 실제 글자 위치를 따라 펜촉과 잉크 표시를 함께 이동하며, 줄바꿈과 화면 폭 변경을 반영한다. 글쓰기가 끝나면 깃펜을 내려놓고 이름 입력을 활성화한다. 움직임 줄이기 설정에서는 완성된 문서를 바로 보여 준다.
- `images/atelier/writing-quill.webp`: 투명 깃펜 이미지. 펜촉 좌표는 이미지의 가로 8%, 세로 96%를 기준으로 한다.

새 CSS/스크립트 내용의 해시를 HTML 경로에 붙이므로 변경 후에는 반드시 빌드를 다시 실행한다. 콘텐츠 검사는 문구·링크·입력·원본 설정을 검증하며, 승인된 이미지와 레이아웃 추가는 허용한다.

## 연필 도판과 장면 구성

일레온(`moooncang/II`)의 큰 그림, 장마다 다른 화면 구성, 선택에 반응하는 연출을 참고했다. 설정·문구·인물 원화는 원본을 유지한다.

- 마을 6단계, 지도와 지역 6곳, 계절 4종, 시작 소품과 장부·문서 테두리를 이미지 생성으로 다시 제작했다. 채색 그림에 필터를 씌우는 방식 대신, 흑연의 해칭과 압력 차이를 표현하는 연필 화풍을 사용한다.
- `hero-crest.webp`는 첫 화면의 참나무·밀 문장, `compass-graphite.webp`는 지도의 나침반이다. `images/ui/season-*-medallion.webp`는 상단 계절 선택과 계절 도판에 공통으로 쓰인다.
- `manuscript.css`는 큰 장 제목, 도면·명부·서류의 서로 다른 배치와 연필 종이 마감을 담당한다. `visual.css`는 첫 화면, 메뉴 표시선, 읽기 진행선, 인물 카드 이동을 담당한다.
- `visual.js`는 기존 `main.js` 다음에 실행된다. 핵심 선택 로직을 바꾸지 않고 메뉴의 마우스·키보드 반응, 카드 이동 버튼, 상태 변경 시 짧은 연출을 추가한다. 움직임 줄이기 설정을 실시간으로 따른다.
- `python3 tests/visual_smoke.py --base-url http://127.0.0.1:8766/`으로 새 메뉴·카드 조작·읽기 진행선·페이지 이동을 검사한다. 전체 기능 검사는 일반 동작과 움직임 줄이기 양쪽을 확인한다.

## 현재 디자인 기준: 작은 만년필 스케치

문구는 사용자와 Claude가 담당한다. 별도 문구 수정 요청이 없는 디자인 작업에서는 최초 원문을 추가·축약·재작성하지 않는다. `tests/preserve_plan.py`의 최초 원문·설정 기준값도 그대로 유지한다.

전체 마을 전경이나 세밀한 판화 대신 영주가 여백에 만년필로 간단히 적어 둔 듯한 작은 스케치를 사용한다. 반듯한 기하학 아이콘, 채운 색면, 금속 메달 표현을 쓰지 않는다. 원래 인물 그림과 입장 화면의 봉투·깃펜 연출은 유지한다.

최종 그림은 사용자가 제시한 르네상스 공학 수기 이미지를 기준으로 삼는다. 건물·장치의 구조를 보여 주는 세피아 펜선, 보조선, 절제된 해칭과 작은 부분 상세를 사용한다. 너무 성긴 낙서나 마을 전체를 채운 전경으로 치우치지 않는다.

- `images/modern/growth-annotated.webp`: 여섯 성장 구조도마다 손글씨 메모 네 묶음을 직접 생성한 시트. 기울어진 필기, 취소선, 화살표와 부분 상세가 한 그림 안에서 함께 전환된다. 메모는 폰트가 아니며 접근성 설명에는 같은 문장을 제공한다. `region-pen.webp`는 지도 지역의 만년필 스케치 시트다. 원래 단계·좌표·수치·조작을 유지한다.
- `images/ui/ink-symbols.webp`, `mode-doodles.webp`: 계절·세력·출발 방식에 사용하는 잉크 스케치. 큰 삽화와 두꺼운 장식을 대신한다.
- `modern.css`, `symbols.css`, `map-modern.css`, `interface-pages.css`: 앞선 스타일 위에 간결한 배치·여백·정렬을 적용한다. 내용은 전부 원문이다.
- `interface-fonts.css`: 명조 제목과 함께 사용하는 Pretendard UI 글꼴. 자체 호스팅하며 라이선스·출처는 `assets/fonts/pretendard/`에 보존한다.
- 본문 페이지의 떠다니는 입자는 끈다. 입장 화면의 원래 연출은 유지한다.
- 다른 화면에 있던 우물·곳간, 세금과 촌락, 가을 공납, 서쪽 통행세 메모도 유지한다. `images/ui/lord-notes-handwritten.webp`에 실제 필기 이미지로 생성하고 `marginalia.css`에서 표시한다. 메모용 폰트는 로드하지 않는다. `aside[data-lord-note]`의 원래 문장은 화면 읽기 도구에 제공하며 보존 검사는 이 네 문장을 별도로 확인한 뒤 최초 본문의 기준값을 그대로 검사한다.

## 전체 화면의 폴리오 마감

현재 기획·화면 순서·원문·인물 원화와 손글씨 도판을 유지하며, 테두리와 표면·조작 상태를 다듬었다. `images/finish/folio-frame.webp`와 `folio-ornaments.webp`는 이미지 생성으로 제작한 투명 세피아 펜화다. 참나무·밀 모서리, 얇은 이중 괘선, 작은 리본 구분선을 사용한다. 프레임의 투명한 중앙은 채우지 않으며, 장식은 클릭을 받지 않는다.

- `finish.css`: 공통 메뉴·제목 괘선·버튼·바닥글과 홈의 성장·세력·계절·출발 카드 마감. 그림과 손글씨의 여백을 유지하고 모바일 모서리 안쪽 공간을 확보한다.
- `finish-pages.css`: 인물 원화의 종이 마운트, 기록·표정 선택, 장부·계산기, 시작 모드와 입력 문서의 이중선·선택·포커스 상태.
- `finish-atlas.css`: 지도·지역 기록의 프레임과 선택 상태, 모바일 지역 버튼, 세계관 설명의 여백. 기존 제목이 30개 그리드 행을 차지하던 문제를 고쳐 설명 사이의 과도한 빈 공간을 없앴다.

`python3 tests/original_smoke.py --site-only`는 18쪽과 주요 기능을 데스크톱·모바일 및 기본·축소 동작 설정에서 검증한다. 상세 입장 애니메이션 행렬은 생략한다. `tests/visual_smoke.py`, `tests/marginalia_smoke.py`, `tests/preserve_plan.py`로 메뉴·카드·필기 에셋·원문 보존을 추가 확인한다.

## 스크롤 장면과 선택 연출

같은 밝은 패널을 반복하던 화면을 기획과 원문 안에서 구분했다. 홈은 여섯 인물의 표지, 큰 성장 도판과 수치 영역, 어두운 책상 위 세력 장부, 대형 가로 인물 전시, 식물 표본을 전환하는 사계, 겹친 출발 문서로 이어진다. 세계 지도·명부·개별 기록·시세 장부·시작 문서도 각각 다른 화면 구성을 사용한다.

- `scenes.css`, `scenes.js`: 홈 장면과 공통 진입·스크롤 진행. 화면 근처의 장면만 요청 프레임에서 갱신하며, 위치 읽기와 스타일 쓰기를 분리한다. 진행 변수는 비상속 속성으로 등록해 실제 움직이는 그림에만 전달하고, 선택에 따른 짧은 연출은 끝나면 해제한다. 스크롤은 기존 선택값을 바꾸거나 휠·터치의 기본 동작을 가로채지 않는다.
- 성장 단계의 원래 여섯 버튼은 기존 도판을 보여 주는 그림 색인으로 표시한다. 데스크톱은 3열, 모바일은 2열이며 클릭·키보드·원래 범위 입력으로 고른 단계만 확정한다. 사계절 표본은 선택 시 그림과 겹종이가 함께 전환된다.
- `visual.js`의 갤러리는 원본 12장과 같은 이미지·이름을 사용하는 썸네일 선택줄을 제공한다. 좌우·Home·End 키로도 선택하며 가로 위치만 바꾼다. 가로 스크롤 영역·썸네일·기존 이전/다음 버튼은 각각 공간을 확보해 네이티브 스크롤바나 포커스 테두리가 서로 겹치지 않는다.
- `scenes-atlas.css`, `scenes-atlas.js`: 접힌 큰 양피지 지도와 그림 지역 목록, 경로 드로잉, 선택 지점의 짧은 잉크 반응, 나침반·포인터 깊이, 지역 기록 전환. 고정 지도가 화면 높이에 들어가지 않으면 일반 문서 흐름으로 돌아간다.
- `scenes-pages.css`, `scenes-pages.js`: 명부의 초상 무대, 넓은 인물 기록과 어두운 표정 장면, 작업 장부, 출발 문서와 작성 공간. 원래 이미지 비율과 조작을 유지한다. 초상과 이름판이 창 높이보다 커지면 고정을 해제하며, 정지한 마우스 아래로 명부가 스크롤되어도 인물 선택이 바뀌지 않는다.
- `images/scenes/survey-orbit.webp`: 투명 측량 보조선 도해. `season-studies.webp`: 봄·여름·가을·겨울의 식물 관측 도판 네 장. 이미지 생성으로 제작했으며 글자나 마을 전경을 추가하지 않는다.
- `desk-studies.webp`: 디바이더·도면, 잉크병·깃펜, 인장·주화의 가로 세 칸. `beginning-studies.webp`: 칙서·인장, 장부·열쇠, 편지·깃펜의 가로 세 칸. 새 이미지 생성으로 제작한 투명 세피아 선화이며 문구·숫자가 없다. 서로 다른 문서 선택과 장부·작성지 여백에 사용한다.
- 모든 연출 모듈은 `window.ERNPresentation.motion`의 같은 환경설정을 사용한다. 사용 중 움직임 줄이기를 켜도 진행 중 연출과 포인터 움직임이 정지한다. 자바스크립트가 없거나 장면 스크립트가 로드되지 않아도 본문과 기본 배치는 보인다.

`python3 tests/scene_smoke.py`는 실제 스크롤과 선택 유지, 키보드 포커스, 실행 중 모션 설정 변경, 고정 영역의 화면 적합성, 자바스크립트 비활성·장면 스크립트 실패 시의 읽기를 검증한다.

`python3 tests/gallery_smoke.py`는 네이티브 스크롤바를 숨기지 않는 브라우저에서 카드 전체 비율, 컨트롤과 숫자의 실제 클릭 가능 영역, 포커스 테두리, 처음·중간·마지막 카드와 썸네일 이동을 검사한다.

## 음악과 배경 음악

`music.html`에서 제공받은 Break Ground, Night Watch on the Wall, Village Fields at Dawn 세 곡을 고르고 재생한다. `_build/music_data.py`가 제목·경로·재생 시간을 관리한다. `images/music/`의 표지 세 장은 제공된 ZIP 안의 1920×1080 JPG를 그대로 사용한다. MP3도 제공된 원본 그대로 보관하며, 음원 내부의 다른 이미지를 사이트 표지로 사용하지 않는다.

- `music.js`: 한 페이지에 하나의 오디오만 만들고 곡·위치·음량·재생 의도를 저장한다. 최초 봉인 열기 또는 명시적인 재생 조작에서 시작한다. 직접 일시정지하면 다음 페이지에서도 유지한다. 처음부터 모든 음원을 내려받지 않는다.
- 일반 HTML 페이지 이동에서는 저장한 곡과 위치에서 재생을 다시 시작하므로 짧은 전환 공백이 있다. 브라우저가 자동 재생을 막으면 실제 재생 상태와 안내를 표시하고, 재생 버튼으로 시작한다.
- 여러 탭이 같은 곡을 겹쳐 재생하지 않도록 활성 플레이어를 조정한다. 기존 효과음과 `M` 단축키는 배경 음악과 별도다. 지원 브라우저에서는 시스템 미디어 조작도 연결한다.
- `music-ui.js`, `music.css`: 음악 페이지와 공통 하단 플레이어가 같은 상태를 표시한다. 원본 표지는 전체 비율을 유지한다. 하단 여백은 실제 플레이어 높이에 맞춰 계산하며, 입장 화면에는 작은 재생 버튼만 표시한다. 자바스크립트가 꺼져 있으면 음악 페이지의 기본 오디오 조작을 제공한다.
- 음악은 다섯 번째 메뉴로 추가한다. 기존 문구·링크 기준값은 바꾸지 않고, 보존 검사가 이 추가 링크의 위치·목적지·문구를 먼저 검증한다.

`python3 tests/music_smoke.py --base-url http://127.0.0.1:8765/`로 실제 음원 재생·위치 이동·상태 복원·탭 전환·반응형 조작을 검증한다. 위의 범위 요청 지원 서버가 필요하다.

## 녹음 기반 효과음

기존의 전자음·백색 잡음 합성을 책·종이·목재·필기 녹음으로 교체했다. 봉인 해제, 종이 넘김, 도장, 필기, 선택, 계절 전환의 여섯 용도에 14개 짧은 WAV를 사용한다. 원문·선택 로직·봉투 애니메이션의 타이밍은 유지한다.

- `_build/sfx_data.py`: 용도별 파일·음량·최소 간격. HTML에 경로와 파일 해시를 넣어 하위 인물 페이지에서도 같은 소리를 불러온다.
- `sfx.js`: 실제 조작 후에만 AudioContext를 연다. 소스는 44.1kHz 모노 PCM16, 합계 약 347KiB다. 처음 봉인을 열 때 사용할 짧은 소리부터 준비하며, 너무 늦게 도착한 소리는 뒤늦게 재생하지 않는다.
- 동일한 소리를 연속으로 반복하지 않고, 음높이·음량의 작은 차이를 준다. 필기는 135–155ms의 세 가지 실제 필기 조각으로, 동시에 하나만 울린다. 전체 동시 재생도 네 개로 제한한다.
- 마우스가 지나갈 때의 소리는 제거한다. 인물 미리보기의 시각 동작은 유지하고, 실제 선택 시에만 소리를 낸다. 한 번의 클릭에 공통음과 전용음이 겹치지 않는다.
- 효과음 버튼과 `M`의 기존 설정을 유지한다. 끄면 재생 중인 소리와 대기 중인 요청도 멈추고, 숨긴 탭의 소리가 복귀 후 쌓여 울리지 않게 한다. BGM의 재생·위치·음량은 건드리지 않는다.
- [효과음 출처와 라이선스](audio/sfx/SOURCES.md): Oculus Audio Pack 01(CC BY 4.0), InspectorJ의 Pencil, Writing, Close, A(CC BY 3.0). 원본·체크섬은 `_build/sfx_sources/`에 보존한다. 필요할 때 `python3 _build/render_sfx.py`로 다시 편집하며 이 별도 작업에는 NumPy·SciPy·FFmpeg가 필요하다. 일반 HTML 빌드에는 추가 패키지가 필요 없다.

`python3 tests/sfx_smoke.py --base-url http://127.0.0.1:8767/`는 실제 WAV 디코딩·첫 조작·음소거·호버·중복 소리·동시 재생 제한·숨김 탭·음원 로드 실패를 검사한다.
