# 변경의 신임 영주가 되었다 — 소개 사이트

크랙 캐릭터 챗 작품 「변경의 신임 영주가 되었다」의 소개 사이트다.

- 사이트: https://moooncang.github.io/ern/
- 기획서: [PLAN.md](PLAN.md) — 컨셉, 쪽별 설계, 글 원칙, 아직 비어 있는 것

## 폴더

```
index.html              입장(서임장)
home.html               첫 화면
world.html              세계
domain.html             영지
characters.html         인물 고르는 화면
char/a.html ~ l.html    인물 상세 12쪽
start.html              시작
assets/css/style.css    모양
assets/js/main.js       동작
images/                 인물 원화 변환본·제작한 UI 삽화
_build/data.py          글과 경로 전부
_build/build.py         쪽을 찍어 내는 스크립트
```

## 고치는 법

HTML은 직접 고치지 않는다. 메뉴와 바닥글이 쪽마다 겹치므로 스크립트가 18쪽을 한 번에 다시 찍는다.

1. 글, 수치, 그림 경로는 `_build/data.py`에서 고친다
2. 사이트 폴더에서 다시 찍는다

```
python _build/build.py
```

3. `main`에 푸시하면 GitHub Pages에 반영된다

`build.py`는 파이썬 기본 기능만 쓴다. 다 찍은 뒤 쪽과 CSS가 가리키는 파일이 실제로 있는지 검사하고, 없으면 멈춘다.

기본 모양은 `assets/css/style.css`, 동작은 `assets/js/main.js`에서 고친다. CSS·스크립트 경로에는 내용 해시가 붙으므로 수정 후 HTML도 다시 생성한다.

## 미리 보기

```
python -m http.server 8765
```

브라우저에서 `http://localhost:8765/`를 연다.

## 원래 기획을 유지한 디자인 보강

문구와 쪽 구성, 인물 구도는 `PLAN.md`를 기준으로 유지한다. `assets/css/materials.css`는 기본 재질, `craft.css`는 내부 화면의 마감·정렬·반응형 배치, `entry.css`는 봉투와 서임장의 표현을 담당한다.

- `images/ui/wax-seal.webp`: 기존 참나무잎 문양으로 제작한 투명 밀랍 에셋. 봉투 봉인과 명부·문서의 인장에 사용한다.
- `images/ui/envelope.webp`, `letter-sheet.webp`: 접힌 덮개·금박·종이 두께를 표현한 봉투와 서임장 이미지. 봉인을 떼면 덮개가 열리고 서임장이 나타난다.
- `images/ui/leather-plate.webp`, `banner-cloth.webp`: 인물·영지 명패와 세력 깃발에 사용하는 가죽·직물 이미지.
- `images/ui/parchment.webp`: 기존 양피지 색 위에 약하게 적용하는 종이결.
- `_build/engraving.py`: 기존 지도·영지 SVG에 더하는 세부 판화선. 설정·지역·성장 단계는 바꾸지 않는다.
- `assets/css/fonts.css`, `assets/fonts/`: 원래 세 글꼴과 두께를 그대로 자체 호스팅한다. OFL 라이선스와 출처는 해당 폴더에 있다.

입장 화면은 320px 모바일부터 가로 화면까지 중앙에 정렬하며, 열린 서임장이 화면보다 길면 세로로 스크롤된다. 키보드로 봉인을 열 수 있고, 이름 입력 중 Enter를 누르면 확인 버튼으로 이동한다. 동작 줄이기 설정도 따른다.

원문·기획 보존 검사는 `python3 tests/preserve_plan.py`로 실행한다. 미리 보기 서버와 Playwright·Chromium을 준비하면 `python3 tests/original_smoke.py --base-url http://127.0.0.1:8766/`으로 18쪽의 기능과 입장 화면의 정렬·키보드 동작을 확인할 수 있다.

## 전체 에셋 적용

초기 기획의 문구·화면 순서·여섯 인물 표지는 유지하며, 코드로 그렸던 시각 요소 위에 제작한 삽화를 적용한다. `images/atelier/`의 WebP는 이 사이트를 위해 이미지 생성으로 제작한 에셋이다. 인물 원화는 교체하지 않는다.

- 영지 성장: 같은 시점과 화풍으로 제작한 개척지부터 대도시까지 여섯 전경. 슬라이더와 기존 수치·시설 설명을 유지한다.
- 약도: 기존 지역 좌표·라벨·경로 위에 손으로 그린 지도와 여섯 지역 풍경을 적용한다. `_build/map_art.py`와 `map-art.css`가 담당한다.
- 세력·사계: 네 가지 자수 깃발과 네 장의 계절 세밀화. `emblems.css`에서 기존 선택·태도 동작과 결합한다.
- 문서: 하사·계승·자유모드 소품 삽화, 금화·은화·동화 장부 삽화, 참나무·밀 테두리 종이를 카드·장부·노트·인물 기록에 재사용한다. 기본 적용은 `atelier.css`, 연필 도판과 문서 배치는 `manuscript.css`가 담당한다.
- 입장: 밀랍 해제 → 덮개 열기 → 편지 꺼내기 → 깃펜으로 칙서 쓰기의 순서로 동작한다. 봉투는 편지 아래에 놓인 채 남는다. 실제 글자 위치를 따라 펜촉과 잉크 표시를 함께 이동하며, 줄바꿈과 화면 폭 변경을 반영한다. 글쓰기가 끝나면 깃펜을 내려놓고 이름 입력을 활성화한다. 움직임 줄이기 설정에서는 완성된 문서를 바로 보여 준다.
- `images/atelier/writing-quill.webp`: 투명 깃펜 이미지. 펜촉 좌표는 이미지의 가로 8%, 세로 96%를 기준으로 한다.

새 CSS/스크립트 내용의 해시를 HTML 경로에 붙이므로 변경 후에는 반드시 빌드를 다시 실행한다. 콘텐츠 검사는 문구·링크·입력·원본 설정을 검증하며, 승인된 이미지와 레이아웃 추가는 허용한다.

## 연필 도판과 장면 구성

일레온(`moooncang/II`)의 큰 그림, 장마다 다른 화면 구성, 선택에 반응하는 연출을 참고했다. 설정·문구·인물 원화는 원본을 유지한다.

- 마을 6단계, 지도와 지역 6곳, 계절 4종, 시작 소품과 장부·문서 테두리를 이미지 생성으로 다시 제작했다. 채색 그림에 필터를 씌우는 방식 대신, 흑연의 해칭과 압력 차이를 표현하는 연필 화풍을 사용한다.
- `hero-crest.webp`는 첫 화면의 참나무·밀 문장, `compass-graphite.webp`는 지도의 나침반이다. `images/ui/season-*-medallion.webp`는 상단 계절 선택과 계절 도판에 공통으로 쓰인다.
- `manuscript.css`는 큰 장 제목, 도면·명부·서류의 서로 다른 배치와 연필 종이 마감을 담당한다. `visual.css`는 첫 화면, 메뉴 표시선, 읽기 진행선, 인물 카드 이동을 담당한다.
- `visual.js`는 기존 `main.js` 다음에 실행된다. 핵심 선택 로직을 바꾸지 않고 메뉴의 마우스·키보드 반응, 카드 이동 버튼, 상태 변경 시 짧은 연출을 추가한다. 움직임 줄이기 설정을 실시간으로 따른다.
- `python3 tests/visual_smoke.py --base-url http://127.0.0.1:8766/`으로 새 메뉴·카드 조작·읽기 진행선·페이지 이동을 검사한다. 전체 기능 검사는 일반 동작과 움직임 줄이기 양쪽을 확인한다.

## 현재 디자인 기준: 작은 만년필 스케치

문구는 사용자와 Claude가 담당한다. 별도 문구 수정 요청이 없는 디자인 작업에서는 최초 원문을 추가·축약·재작성하지 않는다. `tests/preserve_plan.py`의 최초 원문·설정 기준값도 그대로 유지한다.

전체 마을 전경이나 세밀한 판화 대신 영주가 여백에 만년필로 간단히 적어 둔 듯한 작은 스케치를 사용한다. 반듯한 기하학 아이콘, 채운 색면, 금속 메달 표현을 쓰지 않는다. 원래 인물 그림과 입장 화면의 봉투·깃펜 연출은 유지한다.

최종 그림은 사용자가 제시한 르네상스 공학 수기 이미지를 기준으로 삼는다. 건물·장치의 구조를 보여 주는 세피아 펜선, 보조선, 절제된 해칭과 작은 부분 상세를 사용한다. 너무 성긴 낙서나 마을 전체를 채운 전경으로 치우치지 않는다.

- `images/modern/growth-pen.webp`, `region-pen.webp`: 성장 단계와 지도 지역의 작은 만년필 스케치 시트. 원래 단계·좌표·수치·조작을 유지한다.
- `images/ui/ink-symbols.webp`, `mode-doodles.webp`: 계절·세력·출발 방식에 사용하는 잉크 스케치. 큰 삽화와 두꺼운 장식을 대신한다.
- `modern.css`, `symbols.css`, `map-modern.css`, `interface-pages.css`: 앞선 스타일 위에 간결한 배치·여백·정렬을 적용한다. 내용은 전부 원문이다.
- `interface-fonts.css`: 명조 제목과 함께 사용하는 Pretendard UI 글꼴. 자체 호스팅하며 라이선스·출처는 `assets/fonts/pretendard/`에 보존한다.
- 본문 페이지의 떠다니는 입자는 끈다. 입장 화면의 원래 연출은 유지한다.
- 사용자가 따로 요청한 영주 메모 네 개만 `aside[data-lord-note]`에 추가한다. 우물·곳간, 세금과 촌락, 가을 공납, 서쪽 통행세에 관한 메모이며 기존 본문에 섞지 않는다. `marginalia.css`와 자체 호스팅한 `ERN Margin Pen` 글꼴로 표현한다. 보존 검사는 이 네 문장을 별도로 확인한 뒤 최초 본문의 기준값을 그대로 검사한다.
